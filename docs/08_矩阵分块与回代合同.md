# 矩阵分块与回代合同

## 1. 唯一线性化对象

完整 KKT 和递推路线只允许消费同一对象：目标梯度、Hessian、等式残差/Jacobian、不等式残差/Jacobian、松弛、乘子、互补残差、索引和固定零映射。

## 2. 完整原始-对偶 KKT

采用 `c(x)<=0, c(x)+l=0, l>0, z>0`：

`[H A' 0 G'; A 0 0 0; G 0 I 0; 0 0 Z L] * [dx;dy;dl;dz] = [-r_dual;-r_eq;-r_ineq;-r_comp]`。

完整审计路线使用 MATLAB 稀疏反斜杠；只能作为审计基准，不能替代递推失败结果。

## 3. 不等式选择性消元

`D=diag(z./l)`，`W=H+G'*D*G`。实现使用逐元素除法和稀疏逐行装配，禁止形成 `inv(L)`。

## 4. 小时变维块

定义 `v(d,t)=[dx(d,t); dlambda(d,t)]`：

- 主块 `D(d,t)=[Wxx J'; J 0]`
- 相邻连接 `E(d,t)` 只含上一小时 SOC 系数
- 容量列 `B(d,t)=[Wxq; Aq]`
- 右端 `r(d,t)`

风光固定零使小时块自然变维。

## 5. 块 LDL/Thomas 与多右端

每个日期对 `[r | B]` 共 `1+14` 个右端一次求解。每个主元块使用 `ldl(S,'vector')`，支持 1x1/2x2 主元。禁止 `inv`、`pinv`、`lsqminnorm` 和对角逐元素替代 2x2 主元求解。

输出 `a_d=M_d^{-1}r_d` 和 `U_d=M_d^{-1}B_d`，用于构造日响应和全局核心。根据用户于 2026-08-23 确认的新合同，正式日方向优先按递推响应组合 `v_d=a_d-U_d*[Delta q;Delta rho]` 恢复，并用当日原算子对最终组合右端重构高低位残差。只有残差未达到 `1e-10` 时，才复用同一份日块 LDL 因子求解残差校正；不得重新分解日块。原“每次最终方向必须再做一次直接右端回代”的要求不再适用。

## 6. 日响应与 16 维核心

`S_d=C_d-B_d'*U_d`，`c_d=rq_d-B_d'*a_d`。容量绑定消去日容量副本和绑定乘子后，阶段 A 只剩 `[Delta q; Delta rho]` 共 16 维。

核心：

`[Q+sum(S_d), R'; R, 0] * [Delta q; Delta rho] = [bq+sum(gamma_d); -r_dur]`。

常规核心使用 LDL，并保存矩阵、右端、置换、惯性、条件数和对称误差。其 16 维基础矩阵和右端必须直接由当前 `H/A/G/l/z` 与残差按物理消元式重建为 high+low 数对；规范 `partition.global` 的 binary-double 结果只作等价诊断，不能覆盖物理重建值。

日响应累加到 16 维核心矩阵/右端、以及最终响应组合累加到核心残差时，按固定日期顺序使用补偿求和。初次核心 LDL 解之后，用最终核心解逐日形成 `a_d-U_d*g`，再由各日真实矩阵和最终右端审计；只有失败日才复用保留因子校正。若实际恢复后的核心残差尚未达到局部目标，则复用同一份核心 LDL 因子回代校正；最多 10 次，达到 `1e-10` 即提前停止。每日块和核心均不得因该循环重新分解，最终方向仍必须通过完整重构 KKT 残差门槛。

### 6.1 单个联合近零模态的 17 维微边框

若某日存在模型标签可构造的精确关系 `A_d'*a+G_J,d'*b=0`，并且 `d=b'*diag(l./z)*b` 的归一化值不超过 `1e-12`，主流程在日块分解前自动确认唯一的 `(day,terminal_hour)` 候选。候选不是通过硬编码日期或小时指定；若门槛下不是唯一候选，主流程不得强行启用本路线。

确认后，只把该联合坐标保留为一个微边框。定义 `c=G_J,d'*b`、`rho=b'*(r_comp./z-r_ineq)`，以 `alpha=sqrt(d)*gamma` 缩放后，问题日使用

`M_safe*u+C*g+(c/sqrt(d))*alpha=r_safe`

和底行

`(c'/sqrt(d))*u-alpha=rho/sqrt(d)`。

因此核心只从 16 维增至 17 维。问题日先构造与物理消元完全一致的 high+low 目标安全算子，旧 double 安全矩阵只作为一次 LDL 预条件因子；16 个仿射右端和最终 `a-Ug` 都用目标算子残差校正。小核心用不少于 50 位精度求解，并把 high+low 解保持到问题日恢复、不等式乘子恢复和完整 KKT 审计。该路线不得截断秩、删除约束、增加正则项、改变目标函数或回退完整 KKT；正常日仍走 16 维快速路径，所有日期均只做一次日块因子分解。

## 7. 全量回代

按相反顺序恢复：全局容量 -> 日容量副本/绑定乘子 -> 小时块原变量与等式乘子 -> 局部松弛/不等式乘子 -> 规范完整方向 -> 物理数组固定零。

## 8. 连续 6 小时块

日内并行时，24 小时划分为 `1-6,7-12,13-18,19-24`。每块接口为首末两座储能 SOC、14 维容量及当日边框。日内三个内部边界共 6 个 SOC 标量。任务必须按 `(day,block)` 展平，禁止嵌套 `parfor`。

## 9. 诊断

记录每个块的维度、nnz、对称误差、数值秩、条件数估计、LDL 惯性、置换、NaN/Inf。不得自动对称化或自动正则化掩盖错误。
