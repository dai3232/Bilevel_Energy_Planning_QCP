# 复现说明

## 建议环境

- Windows + MATLAB R2024a。
- Parallel Computing Toolbox。
- Git 工作树或独立分支。
- 正式计算阶段关闭互联网。

## 初次复现

1. 运行 `python scripts/validate_starter_package.py` 校验资料包。
2. 在 Codex 打开项目根目录并执行 `交给Codex的首次任务.md`。
3. 阶段 0 通过后，按 `CURRENT_STAGE.md` 依次执行。
4. 每次运行保留 `run_id` 和 Git commit。
5. 重复运行时先比较输入哈希、模型合同版本、索引合同版本和求解器版本。

## 检查点兼容条件

只有以下信息全部一致，才允许从 MAT 检查点恢复：数据哈希、模型合同版本、阶段、火电遍次、活动变量映射、索引版本、代码提交兼容性。
