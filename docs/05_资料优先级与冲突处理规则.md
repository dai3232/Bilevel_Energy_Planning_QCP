# 资料优先级与冲突处理规则

## 领域化权威顺序

| 领域 | 最高权威 | 次级参考 | 禁止做法 |
|---|---|---|---|
| 最新模型口径 | `00_用户确认的模型口径_v1.0.md` | 当前阶段任务书 | 以旧文档覆盖用户确认 |
| 最终数学模型 | `02_最终模型合同_v1.0.md` | 原双层文档 | 自行恢复双层或整数变量 |
| 阶段 A 矩阵与递推 | 阶段 A 技术主依据 | 阳育德论文 | 照搬论文变量或显式求逆 |
| 数值参数与时序 | 两份 Excel | 技术主依据审计摘要 | 在代码中硬编码数值或修改 Excel |
| Codex 工程流程 | 根/目录 AGENTS、阶段长任务、验收矩阵 | OpenAI 官方资料摘要 | 依赖一次聊天提示而不写入仓库 |

## 冲突处理

1. 先确认冲突是否来自不同阶段或不同模型版本。
2. 若高优先级资料已有明确结论，按高优先级执行，并在决策日志记录。
3. 若高优先级资料未覆盖且低优先级资料互相冲突，进入 `NEEDS_MODEL_DECISION`。
4. 不得通过平均、折中、猜测或“常见做法”替代用户决策。
5. 冲突解决后必须更新模型合同、阶段启用矩阵、变更记录和回归测试。

## 历史资料的限制

旧双层模型可用于识别设备、物理候选约束和目标公式，但不得继承：按月双层、每月不同容量、充放电 0-1 状态、长期跨日 SOC。阳育德论文仅提供递推降阶、局部仿射响应、精确等价和并行化思想，不提供本项目的变量、维度或最终实现公式。
