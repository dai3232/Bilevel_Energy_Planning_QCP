# 最终模型合同 v1.0

> 本合同冻结已确认的模型结构；尚未确认的年度多目标组合由 `DECISION-E-*` 管理，Codex 不得自行决定。

## 1. 集合

- 日期 `d in D`：验证时 `D={14,...,20}`，最终 `D={1,...,365}`。
- 小时 `t in T={1,...,24}`，`dt=1 h`。
- 风电 `i in W={1,...,5}`。
- 光伏 `i in P={1,...,5}`。
- 水电 `h in H={1,...,4}`。
- 火电 `f in F={1,...,4}`。
- 储能 `s in S={1,2}`。

## 2. 14 维全局容量顺序

`q=[QW1..QW5, QP1..QP5, QS1,QS2, ES1,ES2]^T`。

容量上下限和单位投资成本只从 `inputs/raw/基础参数.xlsx` 读取。每个日期可建立算法容量副本 `q_d` 并以 `q_d-q=0` 绑定；投资只对全局 `q` 计费一次。

## 3. 运行变量

每小时活动变量按以下规范顺序：

`x(d,t)=[PW_active, PP_active, PH1..PH4, PF1..PF4, Pch1,Pch2, Pdis1,Pdis2, SOC1,SOC2]^T`。

风光可用率为 0 时，变量固定为 0 并从活动变量和两条重合界中删除。

## 4. 当前阶段 A 目标

`min f_A(q)=c_q^T q`。

阶段 A 只保留风电、光伏、储能功率和储能能量投资成本；不重复按日计费。阶段 B-D 在未另行启用目标时继承该目标。

## 5. 最终候选多目标

旧模型和基础参数提供八个候选目标：投资成本、度电成本、弃电率、新能源占比、碳排放、水能利用、火电成本、售电收益。候选形式为：

`F=sum_k omega_k * normalized(F_k)`。

基础参数中的原始权重为 `[0.104,0.060,0.249,0.249,0.104,0.104,0.023,0.104]`，总和为 `0.997`。在 `DECISION-E-01` 和 `DECISION-E-02` 未关闭前，Codex 不得归一化权重、确定归一化分母或把八目标全部启用。

## 6. 小时功率平衡

`sum(PW)+sum(PP)+sum(PH)+sum(PF)+sum(Pdis)-sum(Pch)-Pplan=0`。

`Pplan=10000*Pplan_hat (MW)`。不得创建额外净储能功率变量。

## 7. 风光出力与容量

- `0 <= PW(d,i,t) <= kappaW(d,i,t)*QW_i`
- `0 <= PP(d,i,t) <= kappaP(d,i,t)*QP_i`

当 `kappa=0` 时精确固定变量为 0。

## 8. 水电

小时出力：`0 <= PH(d,h,t) <= PHmax_h`。

阶段 B 加入每日用水上下限：

`W(d,h)=sum_t [a_h*PH(d,h,t)^2+b_h*PH(d,h,t)+c_h]`，

`Wmin(d,h) <= W(d,h) <= Wmax(d,h)`。

参数来自基础参数和输入数据。水量约束属于日级，不建立年度水电出力全局变量。

## 9. 火电

第一次求解：`0 <= PF^(1)(d,f,t) <= PFmax_f`。

掩码：

`m(d,f,t)=0` 当 `PF^(1)<0.3*PFmax`；否则 `m=1`。

第二次求解：

- `m=0`: `PF^(2)=0`，删除活动变量及其界；
- `m=1`: `PFmin_f <= PF^(2) <= PFmax_f`。

火电二次煤耗/成本项仅在相应阶段启用，且属于小时局部 Hessian 贡献。

## 10. 储能

- `0 <= Pch(d,s,t) <= QS_s`
- `0 <= Pdis(d,s,t) <= QS_s`
- 允许两者同时为正。
- `alpha_min*ES_s <= SOC(d,s,t) <= alpha_max*ES_s`，其中 `alpha_min=0.1`、`alpha_max=0.9`。
- `SOC(d,s,1)-0.5ES_s-eta_ch*Pch(d,s,1)*dt+Pdis(d,s,1)*dt/eta_dis=0`。
- `SOC(d,s,t)-SOC(d,s,t-1)-eta_ch*Pch(d,s,t)*dt+Pdis(d,s,t)*dt/eta_dis=0`，`t=2..24`。
- `SOC(d,s,24)-0.5ES_s=0`。
- 日期之间无 SOC 连接。
- 储能时长：`ES_s-Tdur_s*QS_s=0`，两站 `Tdur=2h`。

## 11. 容量界

全局 `q` 使用 Excel 上下限。日容量副本不重复建立独立投资成本；是否给副本建立界由阶段技术主依据决定，但不得产生与全局容量界冲突的重复模型。

## 12. 年度累计指标

阶段 E 可加入年度弃电率、新能源电量占比和保供率等小规模年度边框。应通过日聚合量逐级汇总，不得把 8760 个小时直接形成稠密年度 Jacobian 行并提前消元。

## 13. 当前明确不启用

最小开停机时间、启动/停机成本、充放电互斥 0-1 变量、长期跨日 SOC、按月双层容量、月度独立求解。

## 14. 可行性与失败语义

第二次火电掩码可能导致模型不可行。此时必须报告“固定掩码导致不可行”，不得把它归因于递推算法，也不得擅自改变阈值或 Pmin。
