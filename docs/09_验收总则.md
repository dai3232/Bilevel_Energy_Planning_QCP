# 验收总则

## 阻断原则

只有当前阶段全部 `blocking=true` 的验收项为 `PASS`，才能进入下一阶段。每次运行的实际结果写入 `runs/<run_id>/acceptance/acceptance_results.csv`。

## 方向等价性

- 总体方向相对误差：`||d_rec-d_full||_2/max(1,||d_full||_2) <= 1e-10`。
- 递推方向代回完整 KKT：`||K_full*d_rec-b_full||_2/max(1,||b_full||_2) <= 1e-10`。
- 还应分别报告 `dx,dy,dl,dz` 的相对误差。

## 优化收敛默认值

- 原始等式无穷范数 `<=1e-8`。
- 不等式可行性无穷范数 `<=1e-8`。
- 对偶残差无穷范数 `<=1e-8`。
- 归一化互补间隙 `<=1e-8`。
- 最大迭代次数默认 100；达到上限不等于通过。

这些是初始工程门槛。任何变更必须更新配置、模型合同、变更记录和用户批准，不得在失败后临时放宽。

## Stage A4 用户授权阈值（2026-07-28）

用户明确授权当前 `stage_A4` 使用以下门槛：

- 原始等式残差、不等式残差、缩放坐标对偶残差和缩放坐标互补间隙均为
  `<=1e-6`。
- 完整方向相对误差及递推方向代回完整 KKT 的相对残差均为 `<=1e-6`。
- 完整 KKT 审计方向自身残差仍为 `<=1e-10`，矩阵对称性阈值仍为
  `<=1e-12`，物理违反量仍为 `<=1e-8`。

本授权只适用于当前 A4 正式迭代及其后续新证据。A1、A2、A3 和既有 A4
诊断里程碑继续保留形成其历史结论时的严格门槛；历史 run 不得按新门槛
追溯改判。

## Stage B-2C 用户授权阈值（2026-08-13）

自本次授权后的新运行起，Stage B-2C 的 7/30/60/365 日递推路线统一使用：

- 递推方向代回共享线性化完整 KKT 的相对残差 `<=1e-8`；
- 日内联合块和 16 维全局核心的局部 LDL 求解目标仍为 `<=1e-10`；
- 七日完整 KKT 审计中，递推方向与独立完整方向的相对误差仍为
  `<=1e-10`；独立完整 KKT 方向自身残差仍为 `<=1e-10`；
- 四项 IPM 收敛阈值仍为 `<=1e-6`，最终物理违反量阈值仍为
  `<=1e-8`；
- 日内降阶块、日级边界块和拉格朗日 Hessian 的相对对称性门槛统一为
  `<=1e-10`。

该授权只改变 Stage B-2C 新运行的递推重构 KKT 方向接受门槛和三类矩阵
对称性门槛，不改变模型、目标函数、约束、Newton 方程、步长或最终收敛定义，
也不对矩阵做自动对称化。既有 7 日、30 日及失败运行均保留其生成时的配置
与结论，不追溯改判。

## 物理验收

- 每小时功率平衡。
- 每条 SOC 递推。
- 每日初末 `0.5E`。
- 所有容量、出力、SOC 和水量界。
- 固定零变量精确为 0。
- 第二次火电开机时段满足原始 Pmin，停机时段精确为 0。

## 确定性

相同代码、数据、配置、worker 数和固定汇总顺序重复运行，关键方向、容量、目标和验收指标应在规定容差内一致。

## 性能

性能验收只能在正确性通过后执行。必须分别记录装配、分解、多右端、核心、回代、通信和报告时间，不得只报告 16 维核心时间。
