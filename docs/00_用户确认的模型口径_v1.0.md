# 用户确认的模型口径 v1.0

## 1. 时间与模型层级

- 优化模型是一个统一的单层年度模型，不是按月双层模型。
- 工程验证顺序：先 7 日，再 365 日。
- 每日为独立 SOC 周期：`SOC(d,s,0)=0.5E(s)`，`SOC(d,s,24)=0.5E(s)`。
- 不同日期之间没有 SOC 递推连接。

## 2. 储能

- 不设置充电状态、放电状态或充放电互斥 0-1 变量。
- 每小时保留两个独立连续变量 `Pch(d,s,t)` 和 `Pdis(d,s,t)`。
- 允许 `Pch` 与 `Pdis` 同时为正。
- 不定义净储能功率变量；功率平衡中直接使用 `+Pdis-Pch` 两个项。
- SOC 递推：
  - `t=1`: `SOC_1 - 0.5E - eta_ch*Pch_1*dt + Pdis_1*dt/eta_dis = 0`
  - `t>1`: `SOC_t - SOC_(t-1) - eta_ch*Pch_t*dt + Pdis_t*dt/eta_dis = 0`
  - 末端：`SOC_24 - 0.5E = 0`

## 3. 火电两次连续求解

- 第一次：`0 <= Pf <= Pmax`。
- 生成掩码：若第一次 `Pf < 0.3*Pmax`，第二次固定该时段 `Pf=0`；若等于阈值则保持开机。
- 第二次开机时段：使用 Excel 原始 `Pmin <= Pf <= Pmax`。
- 第二次停机时段：删除该活动变量和上下界，物理输出恢复为精确 0。
- 两次优化本身均为连续优化；阈值映射是两次求解之间的固定外层规则。

## 4. 当前暂缓但必须保留的内容

- `FUTURE-UC-01` 最小开机时间。
- `FUTURE-UC-02` 最小停机时间。
- `FUTURE-UC-03` 启动成本。
- `FUTURE-UC-04` 停机成本。
- `FUTURE-UC-05` 第一次掩码连续时段修复。

## 5. 递推与并行

- 日是第一层天然并行单位，因为每日 SOC 首末固定且不跨日。
- 日内可按连续 6 小时分为 4 个块；块间只通过两座储能的边界 SOC 连接。
- 风、光、水、火小时出力均是局部变量，不需要人为建立对应的全局出力变量。
- 当前阶段 A 的共享核心为 14 个容量方向和 2 个储能时长乘子方向，共 16 维。
