## 2. 当前结论

本次问题不是水量公式写错，也不能据此认定完整 KKT 矩阵秩亏。

问题的实质是：日级二次水量约束使原始不等式残差在 Newton 更新后保留二阶余项；同时，为保持小时递推结构，水量约束被表示为显式日级边框，其中出现 `l_water/z_water`。在固定 `sigma=0.1` 和原、对偶独立步长策略下，互补量及水量乘子下降得显著快于非线性原始残差，最终使日级边框与日块内部矩阵跨越过多数量级。局部日块先失去数值可逆性，而包含全局容量耦合和 16 维核心的整体系统在此前迭代仍可求解。

因此，当前问题属于“内点迭代路径与递推局部分块数值尺度不协调”，而不是“水量约束不可行”或“水量约束算法公式错误”。

## 3. 模型结构变化

### 3.1 日水量函数

对每一天、每一座水电站，日水量函数为：

```math
W(P_H)=\sum_{t=1}^{24}\left(aP_{H,t}^{2}+bP_{H,t}+c\right).
```

对应的上下界约束为：

```math
g_u(P_H)=W(P_H)-W_{\max}\leq 0,
```

```math
g_l(P_H)=W_{\min}-W(P_H)\leq 0.
```

其梯度和 Hessian 满足：

```math
\nabla g_l=-\nabla g_u,
\qquad
\nabla^2 g_l=-\nabla^2 g_u.
```

当前七日对象包含：

- 7 天；
- 每天 4 座水电站；
- 每座水电站 1 条上界和 1 条下界；
- 共 `7 × 4 × 2 = 56` 条水量不等式；
- 每条约束同时连接同一电站同一天的 24 个 `PH` 变量；
- 每个日块新增 8 维水量边框。

### 3.2 为什么不能把水量行作为普通小时行处理

Stage A 的主要约束可以按照小时组织成块三对角链。水量约束同时连接一天的 24 个小时。如果直接将水量行消元到既约 Hessian 中，会产生：

```math
G_w^\mathsf{T}\operatorname{diag}(z_w/l_w)G_w,
```

该项会把同一水电站一天内的 24 个小时两两连接，破坏原来的小时块三对角结构。

为保留递推路线，当前实现将每天 8 条水量行保留为显式边框。每个日块求解：

```math
\begin{bmatrix}
M&T^\mathsf{T}\\
T&-D_w^{-1}
\end{bmatrix}
\begin{bmatrix}
v\\
\eta
\end{bmatrix}
=
\begin{bmatrix}
r_v\\
r_w
\end{bmatrix},
```

其中：

```math
D_w=\operatorname{diag}(z_w/l_w),
\qquad
D_w^{-1}=\operatorname{diag}(l_w/z_w),
```

`T` 是水量 Jacobian 在当前日链局部变量上的限制，`eta` 对应水量不等式乘子方向。

这种表示在精确算术下与完整不等式消元严格等价，但它会显式暴露 `l_w/z_w` 的极端尺度。

## 4. 非线性原始残差为什么没有随互补量同步下降

原始不等式残差定义为：

```math
r_{ineq}=g(x)+l.
```

Newton 方向中的松弛变量满足：

```math
\Delta l=-r_{ineq}-G\Delta x.
```

若原变量使用步长 `alpha_p`，则更新后的水量残差为：

```math
g(x+\alpha_p\Delta x)+l+\alpha_p\Delta l
=
(1-\alpha_p)r_{ineq}
+\frac{\alpha_p^2}{2}
\Delta x^\mathsf{T}\nabla^2g\Delta x.
```

对于 Stage A 的线性约束，Hessian 为零。当 `alpha_p=1` 时，原始残差理论上可以在一次 Newton 更新后降至舍入误差量级。

对于 Stage B-2C 的二次水量约束，即使 `alpha_p=1`，仍保留二阶项：

```math
r_{ineq}^{+}
=\frac{1}{2}\Delta x^\mathsf{T}\nabla^2g\Delta x.
```

因此，水量约束加入后，不能再期待完整原变量步长自动把全部不等式残差一步消除。

## 8. 为什么局部日块失败而完整系统仍可能可解

递推算法要求先独立求解每个日块，形成每日容量响应，再聚合为 16 维全局核心。因此它隐含要求每个被消元的日级主块在当前数值精度下可解。

完整系统同时保留：

- 七个日块；
- 14 个全局容量变量；
- 2 个时长乘子；
- 每日容量副本与全局容量之间的绑定关系。

一个主子块可以是奇异或近奇异的，而包含额外边框耦合的完整鞍点矩阵仍然非奇异。全局容量和 16 维核心可能约束住日块内部的局部零方向。

截至第 40 次附近，独立全局既约鞍点审计仍能给出可接受方向，而局部日块随后失效。这表明当前证据支持“局部分块数值可逆性先丧失”，不支持“完整 KKT 已经整体秩亏”。第 41 次在完成独立全局审计之前停止，因此也不对第 41 次完整系统作未经运行验证的可解性声明。

## 9. 上下界水量行对局部曲率的影响

同一日、同一电站的上下界梯度互为相反数，Hessian 也互为相反数。它们对拉格朗日 Hessian 的合计贡献为：

```math
z_u\nabla^2g_u+z_l\nabla^2g_l
=(z_u-z_l)\,2aI.
```

当上下界均为非活动约束且乘子趋近零时，这部分曲率也趋近零。因此：

- 上下界两条 Jacobian 行在方向上相关；
- 它们在精确算术下由不同的 `l/z` 对角项区分；
- 乘子塌缩后，它们不能为日块提供稳定的局部曲率；
- 日块的某些方向需要依赖全局容量耦合才能被约束。

这进一步解释了为什么问题首先出现在“独立日块消元”而不是水量物理可行性检查中。

## 12. 当前候选解决方向

当前优先候选是只针对 Stage B-2C 将原、对偶独立应用步长改为共同应用步长：

```math
\alpha=\min(\alpha_p,\alpha_d),
```

并统一更新：

```math
x^+=x+\alpha\Delta x,
\quad
l^+=l+\alpha\Delta l,
\quad
y^+=y+\alpha\Delta y,
\quad
z^+=z+\alpha\Delta z.
```

该方案的目标不是修改水量公式，也不是修补 Schur 矩阵，而是防止对偶乘子和互补量在非线性原始可行性尚未收敛时继续超前塌缩。

其特点为：

- 不改变 Newton 方程；
- 不改变水量约束、残差、Jacobian 或 Hessian；
- 不改变日块、每日响应或 16 维核心结构；
- 不引入正则化和完整方向回退；
- 会改变正式 IPM 状态更新策略和迭代轨迹。

由于这是算法策略变更，而不是纯数值实现修复，当前尚未实施，需由用户明确确认。共同步长是基于当前证据的首选候选，但在从第 0 次迭代完成正式运行前不能预先宣称它一定解决问题。

其他理论路线及其当前边界：

| 路线 | 可能作用 | 当前限制 |
|---|---|---|
| 动态 `sigma` 或预测—校正 | 让中心参数适应非线性原始残差 | 当前配置明确关闭，会改变冻结算法策略 |
| 非线性线搜索 | 控制水量二阶余项 | 当前明确关闭，属于更大算法变更 |
| 扩大全局核心 | 把日块数值零方向提升到全局层 | 破坏正式 16 维核心合同 |
| 全局既约方向直接更新 | 绕过局部日块可逆性要求 | 违反正式递推路线要求 |
| 正则化或伪逆 | 可在数值上绕过零枢轴 | 项目合同明确禁止 |
