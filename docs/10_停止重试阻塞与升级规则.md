# 停止、重试、阻塞与升级规则

## 状态

- `PASS`：全部阻断性验收通过。
- `FAIL_RETRYABLE`：已定位为可修复的代码、索引、符号或数值实现问题。
- `BLOCKED_EXTERNAL`：MATLAB、许可证、权限、硬件、文件损坏等外部阻塞。
- `NEEDS_MODEL_DECISION`：模型合同未覆盖或资料冲突，必须由用户决定。

## 失败闭环

1. 记录失败测试、症状、原始错误和证据路径。
2. 给出根因假设，禁止直接改阈值。
3. 做最小修复并记录代码提交。
4. 重新运行失败测试和受影响回归测试。
5. 更新 `issue_log.csv` 和中文问题修复报告。
6. 只有全部阻断项通过才结束阶段。

## 必须停止并升级的情况

- 受控输入被修改或哈希不一致。
- 发现用户未提交且来源不明的代码改动。
- 模型公式、目标权重或阶段启用范围存在未决冲突。
- 同一根因连续三轮修复无实质进展。
- 需要使用禁止方法或改变物理模型才能继续。

## 禁止的“假成功”

- 删除失败测试。
- 把阈值改宽。
- 用完整 KKT 方向替代递推方向。
- 添加未批准正则项、随机 Hessian或伪逆。
- 仅检查目标值相近而不比较完整方向。
- 把外部阻塞标记为通过。
