## 2. 设计约束

### 2.1 必须保持

1. 原始步长和对偶步长按照论文公式分别计算：

```math
S_p=\tau\min\left\{
\min_{\Delta l_i<0}\left(-\frac{l_i}{\Delta l_i}\right),1
\right\},
```

```math
S_d=\tau\min\left\{
\min_{\Delta z_i<0}\left(-\frac{z_i}{\Delta z_i}\right),1
\right\},
```

其中 `tau=0.9995`。

2. 原始变量与松弛变量使用 `S_p`：

```math
x^+=x+S_p\Delta x,
\qquad
l^+=l+S_p\Delta l.
```

3. 等式乘子与不等式乘子使用 `S_d`：

```math
y^+=y+S_d\Delta y,
\qquad
z^+=z+S_d\Delta z.
```

4. 当前模型口径保持不变：

- 日期为第14—20日；
- 每天24小时；
- 每天SOC首端和末端均为 `0.5E`；
- 日期之间无SOC连接；
- `Pch` 和 `Pdis` 保持两个独立连续变量；
- 固定零变量值和方向保持精确0；
- 14个全局容量变量和2个全局时长乘子语义不变。

5. 完整 KKT 审计方向和递推方向必须消费同一个 `linearization` 对象。

### 2.2 禁止事项

- 不使用 `inv`、`pinv` 或 `lsqminnorm`；
- 不增加正则化；
- 不增加隐藏扰动或数值修复项；
- 未经用户明确授权，不调整方向、残差或收敛阈值；
- 不用完整 KKT 方向替换递推方向；
- 不将整日、30天或365天矩阵转换为 `full`；
- 不修改水量函数、Jacobian、Hessian或边界数据；
- 不修改论文步长公式；
- 不把失败自动解释为成功。

## 3. 当前路线的问题

当前递推路线没有将56条水量不等式方向完全消入既约矩阵，而是将每天8条水量乘子方向保留为显式边框变量：

```math

```

每天求解的矩阵包含：

```math
\begin{bmatrix}
M_d&T_d^\mathsf T\\
T_d&-\operatorname{diag}(l_{w,d}/z_{w,d})
\end{bmatrix}.
```

对于非活动水量约束，`l_water` 保持为正常正数，而 `z_water` 沿中心路径逐步趋近零，因此：

```math
l_{water}/z_{water}\rightarrow +\infty.
```

已保存的第34次迭代状态中，水量 `l/z` 最大值已经达到约 `1.37e18`。该矩阵表示在精确算术中与完整不等式消元等价，但在双精度局部日块分解中会显式暴露极端尺度。

## 4. 第一级：完全消去全部不等式方向

### 4.1 完整 Newton 方程

当前线性化对象提供：

```math
H\Delta x+A^\mathsf T\Delta y+G^\mathsf T\Delta z=-r_{dual},
```

```math
A\Delta x=-r_{eq},
```

```math
G\Delta x+\Delta l=-r_{ineq},
```

```math
Z\Delta l+L\Delta z=-r_{comp},
```

其中：

```math
L=\operatorname{diag}(l),
\qquad
Z=\operatorname{diag}(z).
```

### 4.2 消去 `Δl` 和 `Δz`

由不等式原始残差方程得到：

```math
\Delta l=-r_{ineq}-G\Delta x.
```

由互补方程得到：

```math
\Delta z
=\operatorname{diag}(z/l)G\Delta x
-\frac{r_{comp}-z\odot r_{ineq}}{l}.
```

定义：

```math
\theta=z/l,
```

```math
\phi=(r_{comp}-z\odot r_{ineq})/l.
```

代回驻点方程，得到唯一的既约鞍点系统：

```math
W=H+G^\mathsf T\operatorname{diag}(\theta)G,
```

```math
b_x=-r_{dual}+G^\mathsf T\phi,
```

```math
\begin{bmatrix}
W&A^\mathsf T\\
A&0
\end{bmatrix}
\begin{bmatrix}
\Delta x\\
\Delta y
\end{bmatrix}
=
\begin{bmatrix}
b_x\\
-r_{eq}
\end{bmatrix}.
```

新策略要求对全部7304条不等式统一执行上述消元，不能再把最后56条水量行作为例外保留。

### 4.3 水量约束在既约矩阵中的位置

对第 `d` 天的水量 Jacobian `T_d`，水量不等式消元贡献为：

```math
T_d^\mathsf T
\operatorname{diag}(z_{w,d}/l_{w,d})
T_d.
```

该项只连接：

- 同一天；
- 同一水电站；
- 该站当天24个 `PH` 变量。

它不会产生跨日非零元。每天4座水电站、上下界共8条水量行，每行只有24个 Jacobian 非零元，因此该更新可以保持稀疏，不需要形成稠密整日矩阵。

拉格朗日 Hessian 中原有的水量二阶项保持不变：

```math
H=H_{objective}+\sum_i z_i\nabla^2g_i.
```

新策略只改变不等式方向的消元表示，不改变水量 Hessian 的定义、符号或乘子权重。

## 5. 第二级：日内联合块

### 5.1 全局变量

全局保留变量为：

```math
g=
\begin{bmatrix}
\Delta q\\
\Delta\rho
\end{bmatrix},
```

其中：

- `Δq`：14个全局容量方向；
- `Δrho`：2个全局时长约束乘子方向。

因此：

```math
\dim(g)=14+2=16.
```

### 5.2 每日局部变量

第 `d` 天的联合局部变量为：

```math
u_d=
\begin{bmatrix}
\Delta q_d\\
\Delta\pi_d\\
\Delta v_d
\end{bmatrix}.
```

其中：

- `Δq_d`：当天14个容量副本方向；
- `Δpi_d`：当天14个容量绑定乘子方向；
- `Δv_d`：当天24小时内全部原始变量方向和小时等式乘子方向。

`Δv_d` 中不再包含水量 `eta`，因为全部水量 `Δl、Δz` 已在第一级消去。

### 5.3 日内联合矩阵

在当前排列下，日内联合块具有以下结构：

```math
D_d=
\begin{bmatrix}
C_d&I&B_d^\mathsf T\\
I&0&0\\
B_d&0&\widetilde M_d
\end{bmatrix},
```

其中：

```math
\widetilde M_d
=M_{base,d}
+T_d^\mathsf T
\operatorname{diag}(z_{w,d}/l_{w,d})T_d.
```

`M_base,d` 已包含当前拉格朗日 Hessian，包括 `z_water` 加权的水量约束 Hessian。

七日对象的预期日内联合块维数为：

```text
[617, 618, 617, 618, 618, 618, 618]
```

相对于当前显式水量边框路线，每天不再额外增加8个 `eta` 变量。

### 5.4 全局—日块箭头结构

经过统一排列后，完整既约矩阵写成：

```math
\begin{bmatrix}
K_g&E_1^\mathsf T&E_2^\mathsf T&\cdots&E_D^\mathsf T\\
E_1&D_1&0&\cdots&0\\
E_2&0&D_2&\cdots&0\\
\vdots&\vdots&\vdots&\ddots&\vdots\\
E_D&0&0&\cdots&D_D
\end{bmatrix}
\begin{bmatrix}
g\\u_1\\u_2\\\vdots\\u_D
\end{bmatrix}
=
\begin{bmatrix}
b_g\\b_1\\b_2\\\vdots\\b_D
\end{bmatrix}.
```

日块之间没有直接非零耦合。所有跨日关系都通过16维全局变量 `g` 传递。

## 6. 第三级：每日14维响应与固定16维核心

### 6.1 单次日块分解和多右端求解

第 `d` 天满足：

```math
D_du_d+E_dg=b_d.
```

因此：

```math
u_d=D_d^{-1}b_d-D_d^{-1}E_dg.
```

定义：

```math
a_d=D_d^{-1}b_d,
```

```math
U_d=D_d^{-1}E_d.
```

实际实现禁止显式求逆。每个 `D_d` 只做一次稀疏对称带主元 LDL，然后用同一因子同时求解：

- 1个物理残差右端；
- 14个全局容量方向右端。

`E_d` 对2个 `rho` 方向没有日内直接耦合，因此物理上只需要14个容量响应列。

### 6.2 每日14维响应

从 `u_d` 中提取每日容量绑定乘子方向：

```math
\Delta\pi_d=p_d+S_d\Delta q,
```

其中：

- `p_d`：14维每日基础响应；
- `S_d`：14×14每日容量响应矩阵。

“每日14维响应”不是说每天只有14个未知量，而是说每天约617个局部未知量经过精确消元后，只向全局层暴露14维容量端口。

### 6.3 聚合为16维核心

将所有日块响应代回全局方程，得到标准 Schur 核心：

```math
K_{core}
=K_g-\sum_{d=1}^{D}E_d^\mathsf TD_d^{-1}E_d,
```

```math
b_{core}
=b_g-\sum_{d=1}^{D}E_d^\mathsf TD_d^{-1}b_d.
```

根据具体变量和方程符号，代码中的每日响应可能以加号形式累计；权威定义必须来自上述完整分块矩阵的 Schur 补，不能根据变量名称手工猜测符号。

最终只求解：

```math
K_{core}g=b_{core},
```

且：

```math
\dim(K_{core})=16.
```

## 7. 反向恢复

### 7.1 恢复每日日内方向

求得全局 `g=[Δq;Δrho]` 后，各天相互独立地恢复：

```math
u_d=a_d-U_dg.
```

从 `u_d` 中按 canonical index 精确取回：

- `Δq_d`；
- `Δpi_d`；
- 每小时原始变量方向；
- 每小时等式乘子方向。

恢复顺序应从全局层返回日层，再按当天固定小时排列写回 canonical 方向。不得自动排序、重排或修正索引。

### 7.2 统一恢复全部不等式方向

所有 `Δx、Δy` 恢复后，统一执行：

```math
\Delta l=-r_{ineq}-G\Delta x,
```

```math
\Delta z=(-r_{comp}-z\odot\Delta l)/l.
```

这里同时恢复：

- Stage A 的7248条不等式方向；
- Stage B 的56条水量不等式方向。

水量 `Δz` 不再在日块内部以 `eta` 的形式单独求解。

### 7.3 固定零变量

固定零变量的当前值和方向必须在恢复后的 canonical 方向中继续保持精确0。不得通过先求非零方向再强制清零掩盖分区或索引错误。

## 9. 理论等价性

如果满足以下条件：

1. 全部不等式消元公式与完整 Newton 方程严格一致；
2. 变量排列是 canonical reduced index 的双射；
3. 每个 `D_d` 可以稳定分解；
4. Schur 核心按照完整分块矩阵形成；
5. 反向恢复使用同一组日块因子和响应；
6. `Δl、Δz` 使用原始完整残差统一恢复；

则在精确算术中：

```math
\Delta_{recursive}=\Delta_{full\ reduced\ KKT}
=\Delta_{full\ KKT}.
```

该策略不应改变 Newton 方向、论文步长、状态更新公式或理论迭代次数。若方向差异超出既有 `1e-10` 阈值，应判定实现失败，不能解释为允许的算法差异。

## 10. 固定16维核心成立的必要条件

本策略不能绕过一个基本数学条件：

> 每个被局部消元的日内联合块 `D_d` 必须在当前数值精度下可稳定求解。

完全消去水量方向可以去掉显式 `l_water/z_water`，联合日块分解也允许在 `q_day、pi_day` 和小时变量之间统一选取主元。这有可能消除当前路线的数值失效，但不能仅凭推导预先保证所有日块一定非奇异。

如果某个 `D_d` 在精确意义上真正奇异，则完整全局矩阵仍可能因全局耦合而非奇异。此时在同时禁止：

- 伪逆；
- 正则化；
- 完整方向回退；
- 扩大全局接口；

的条件下，不存在合法的固定16维 Schur 消元。

因此，失败检查点上的日块可分解性是本策略的实施门禁，不是可以跳过的防御性检查。若该门禁失败，应停止并进入 `NEEDS_MODEL_DECISION`，由用户决定是否把未被局部约束的方向提升到全局接口。

## 11. 7天、30天和365天扩展

在当前模型中，每日水量约束和SOC均不跨日，跨日共享量只有14个全局容量和2个全局时长乘子，因此理论结构为：

| 天数 | 独立日块数量 | 每日端口响应 | 最终全局核心 |
|---:|---:|---:|---:|
| 7 | 7 | 每天14×14 | 16×16 |
| 30 | 30 | 每天14×14 | 16×16 |
| 365 | 365 | 每天14×14 | 16×16 |

全局既约矩阵规模近似为：

```math
N(D)\approx16+617D.
```

对应规模约为：

| 天数 | 全局既约矩阵近似维数 |
|---:|---:|
| 7 | 4340 |
| 30 | 18526 |
| 365 | 225221 |

递推路线不直接分解上述全局矩阵，而是分解 `D` 个约617维日块，并求解一个16维核心，因此在每天结构固定时，总工作量随天数近似线性增长：

```math
O(D\,C_{day})+O(16^3).
```

### 11.1 并行性

形成每日响应时，各天相互独立：

```text
day 1   → local LDL → 14×14 response ┐
day 2   → local LDL → 14×14 response ├→ deterministic sum → 16×16 core
...                                     │
day D   → local LDL → 14×14 response ┘
```

全局核心求解后，各天的反向恢复也相互独立。

### 11.2 内存控制

365天实现可以按批次处理日块：

1. 组装一个或一批日块；
2. 分解并形成响应；
3. 累加全局核心；
4. 保存回代所需因子或可重建的小型元数据；
5. 处理下一批日块。

不得为了方便把365天完整既约矩阵转换为稠密矩阵。

### 11.3 全局核心何时会增长

当前固定16维结论依赖现有模型口径。如果以后新增：

- 年度总水量约束；
- 跨日水库状态；
- 跨日SOC连接；
- 跨日启停逻辑；
- 其他年度共享状态；

则这些变量或乘子属于真正的全局接口，核心维数必须按照新模型合同重新推导，不能继续机械声称固定16维。

## 12. 理论性能边界

该策略主要减少每次 Newton 方向的求解成本，不减少内点法迭代次数。

对于具有理想变量排序的通用稀疏 LDL，求解器也可能隐式识别日块和16维分隔变量。因此，显式递推相对于理想通用稀疏求解器并不必然获得数量级上的渐近复杂度优势。

显式三级递推的主要收益是：

- 固定并公开消元顺序；
- 每个日块只分解一次；
- 15个右端复用同一因子；
- 每日响应可以并行；
- 反向恢复可以并行；
- 内存可以按日或按批次控制；
- 全局核心维数可验证；
- 每一层均可与完整矩阵逐项审计。

七日对象主要用于证明数学等价，不保证墙钟时间一定快于 MATLAB 高度优化的全局稀疏求解器。30天和365天才是主要性能验证范围。

## 13. 完整 KKT 审计与性能运行的关系

七日正式验证应继续要求递推方向和独立完整方向消费同一 `linearization`，并逐次验证方向等价。

如果30天或365天的每次迭代仍然额外求解一次完整全局方向，则整体墙钟时间仍会被完整审计路线支配，无法体现递推加速。后续性能阶段需要单独确定完整方向抽查策略，但在新的验证策略获得用户批准之前，不得自行减少当前七日审计。

- 日响应：只输出14维容量端口响应；
- 聚合：确定性累加所有日响应；
- 核心：保持14个容量加2个时长乘子的16维对象；
- 恢复：先恢复全部 `Δx、Δy`，再统一恢复 `Δl、Δz`；
- 审计：继续使用独立完整路线比较方向和残差。

### 14.3 正式运行顺序

1. 失败检查点结构诊断；
2. 新增和修改文件的最小固定测试；
3. 受影响的 Stage A4/B-2B 回归；
4. 从第0次状态通过 `RUN_PROJECT.m` 启动全新七日正式运行；
5. 七日通过后再设计30天扩展验证；
6. 30天通过后再进入365天性能运行。

## 15. 最小验收条件

- 每个日块保持 sparse 和对称；
- 每天只分解一次；
- 每天同时求解1个物理右端和14个容量方向；

- 每个右端残差满足现有阈值；

### 15.3 响应与核心层

- 全局核心严格为16×16；
- 核心保持对称；
- 核心残差满足现有阈值。

### 15.4 恢复与等价层

- `Δx、Δy、Δl、Δz` 维数与 canonical index 闭合；
- 固定零方向精确为0；
- `Δl、Δz` 满足原不等式和互补方程；
- 递推完整 KKT 相对残差满足当前授权门槛 `1e-8`；
- 递推方向与独立完整方向相对误差满足 `1e-10`；
- 未消费完整方向更新状态；
- 论文原始/对偶独立步长保持不变。

## 17. 风险与停止条件

### 17.1 日内联合块仍不可分解

如果完全消去水量方向后，失败检查点上的某个 `D_d` 仍然不能稳定分解，则说明问题不仅来自显式 `l/z` 水量边框，局部日块还存在需要全局变量约束的真实或数值零方向。

此时必须停止，不能：

- 增加正则化；
- 使用伪逆；
- 返回完整方向；
- 删除失败日；
- 未经用户明确授权再次放宽当前残差阈值。

应记录具体零方向和其与全局容量变量的耦合，再由用户决定是否扩大接口核心。

### 17.2 非线性原始残差仍下降较慢

本策略修改线性系统表示，不修改内点路径。水量约束的二阶线性化余项仍然存在，因此不等式原始残差可能继续比互补量下降得慢。

新策略可以避免当前显式 `l/z` 边框率先溢出或失去数值秩，但不能在正式运行之前承诺一定改变收敛迭代数或保证最终收敛。

### 17.3 通用稀疏求解器可能同样高效

七日规模下，全局稀疏求解器可能比显式递推更快。该现象不否定递推算法；性能结论必须在30天和365天对象上，通过相同硬件、相同线性化和相同方向精度比较。

## 18. 完成定义

本策略只有在以下条件全部满足后才算完成：

1. 失败检查点上的7个新日内联合块全部稳定可解；
2. 水量 `eta` 和 `l/z` 日边框已从正式递推路线移除；
3. 全部不等式方向只在末端统一恢复；
4. 每日14维响应和固定16维核心结构成立；
5. 递推方向与独立完整方向满足既有严格阈值；
6. 论文原始/对偶独立步长保持原式；
7. 七日完整正式运行从第0次状态收敛并生成合格证据；
8. 未使用正则化、伪逆或完整方向回退；数值门槛仅按用户明确授权修改；
9. 只有七日通过后，才允许继续30天和365天扩展验证。
