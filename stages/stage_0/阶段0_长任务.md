# 阶段0：环境、数据与工程基础设施：长任务

## 目标

建立可复现仓库、数据读取、唯一索引框架、运行工件、报告和阶段状态机，不实现求解器。

## 数据窗口

不执行优化；只审计完整两份 Excel。

## 前置条件

- `CURRENT_STAGE.md` 指向 `stage_0` 且状态为 `READY`；对于 stage_E/F 还必须关闭相应决策门禁。
- 上一阶段阻断性验收全部通过。
- 输入哈希、模型合同版本和代码提交已写入 run manifest。

## 本阶段范围

- MATLAB 环境与许可证检查
- 输入哈希和标签式读取器
- 规范数据结构
- 唯一索引/固定零映射框架
- run_id 工件管理
- 验收执行器和中文 Word 报告框架

## 明确不在本阶段

- 完整 KKT
- 递推求解器
- 内点迭代
- 任何优化结果

## 里程碑与执行顺序

1. 初始化 Git/工作树和目录
2. 实现数据读取与校验
3. 建立配置加载和合同版本字段
4. 实现索引对象框架
5. 实现运行目录与日志模板
6. 实现报告生成烟雾测试
7. 执行全部阶段0验收

## 必须交付

- 数据审计 CSV
- 环境 CSV
- 运行清单 JSON
- 阶段0两份中文 Word 报告
- 更新后的状态日志

## 验收

逐项执行 `阶段0_验收矩阵.csv`。实际值和证据写入运行目录的 `acceptance_results.csv`。任何阻断项失败都不得进入下一阶段。

## 完成条件

- 运行终态为 `PASS`。
- 问题日志中没有未解释的阻断问题。
- 两份中文阶段报告已经从真实工件生成。
- 状态日志记录本阶段最后 run_id、Git commit、测试命令和结论。
- 仅在以上条件满足时，下一阶段可设为 `stage_A1`。
